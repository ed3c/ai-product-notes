# Opportunity roadmap

The roadmap records evidence state, not aspiration. Allowed states:

```text
WATCH
VALIDATE
BUILD
BLOCKED
REJECTED
```

`BUILD` requires the compiler gate plus direct paid demand and Human Admit. `PAID`, `MARKET_VALIDATED`, `SHIPPED` and `DONE` are not roadmap states; they require separate receipts and must not be inferred from code or PR publication.

Each active item links its canonical opportunity packet, experiment contract, current gaps, next evidence and stop-loss. Historical items are superseded or rejected explicitly rather than deleted.
