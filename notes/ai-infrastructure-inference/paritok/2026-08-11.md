# Paritok — 2026-08-11

## 繁體中文

### 產品與訊號

- 類別：Coding Agent Context Compression / AI Infrastructure
- 監控日期：2026-08-11
- Product Hunt：`Launching today`，當日 #3，約 235 points。
- Official: https://www.paritok.com/
- GitHub: https://github.com/Paritok-official/paritok-4b-v1
- Model: https://huggingface.co/paritok/paritok-4b-v1

Paritok 是 coding-agent request compression gateway，放在 Claude Code、Codex、Cursor、OpenHands 等 agent 與 upstream model API 之間，壓縮 tool schemas、file/tool output 與 stale history，並保留 `read_original` 類 recall path。

### 商業模式與 WTP

Self-host 為 Apache-2.0 免費；Hosted GPU 公開價格為 US$0.30 / 1M processed tokens，2026-08 月底前 launch promotion 免費。這代表 cost-saving value 可直接轉成 usage-based pricing。

內部 Best 評分：WTP 8 / Funding Scale 3 / User Traction 6 / Market Gap Moat 8，Composite 6.35。

### 技術證據

官方資料顯示：
- tool schema example 約 29K → 8K tokens/turn；
- file reads / tool output 約縮到原本 26%；
- Paritok-4B-v1 為 4B LoRA，模型頁標示 Apache-2.0；
- model card 自報 SWE-bench Verified quality retained 86.5%、compression rate 25.7%；
- training data 規模為 45K coding-agent trajectory samples；
- 官方也明確列出 rare identifier loss 與 Python-heavy / English-heavy distribution 等限制。

上述 performance 數字屬 upstream self-reported evidence，不應當成獨立第三方 benchmark。

### License gate

- Repository code/gateway：primary repo LICENSE = Apache-2.0。
- Paritok-4B-v1 adapter weights：Hugging Face model card = Apache-2.0。
- Base model Qwen3-4B-Instruct-2507：Hugging Face model card = Apache-2.0。
- 45K trajectories：目前沒有足夠證據證明完整 trajectory dataset 以可再利用資料集形式公開並附獨立 commercial license，因此 **不得**把 training trajectories 當成可商用 data/trajectory asset 排名。

### 市場 Gap 與競爭

競品包含 Edgee、Context Gateway、LLMLingua 類 compression，以及 provider-native caching/context management。Gap 不在「再做一個 proxy」，而在 production context budget governance：知道哪一塊 context 貴、哪一塊可安全壓縮、壓縮是否傷害 task success、何時需要 recall/fallback。

### Solopreneur MVP — Coding-Agent Context Cost Guard

Target：Claude Code / Codex / Cursor 重度使用團隊，尤其 MCP-heavy workflows。

MVP：
1. Local/OpenAI-compatible proxy，預設不改內容，只量測。
2. 將 request 拆成 system、tools、history、file/tool output。
3. 顯示每個 repo / task / agent 的 context cost attribution。
4. 對 oversized tool surface、重複 file reads、stale history 發警告。
5. 可選 reversible compression，必須有 identifier check 與 raw fallback。
6. PR / CI 報告「本次 agent workflow 估算多花多少 token」。

建議收費：US$29–99/developer/month，team policy / budget dashboard US$199–499/month；也可採 savings-linked pricing，但初期不建議，因 attribution 複雜。

### 兩週驗證

- 支援 Claude Code + Codex 兩個 request shape。
- 收集 10 位開發者、至少 100 個 session 的匿名 cost breakdown。
- 不啟用 compression 先證明至少可找出 20% 可移除/重複 context。
- 再對 20 個固定 coding tasks 做 reversible compression A/B。
- 通過條件：median input cost 降低 >=25%，task success regression <3%，且 2 個 team 願付 US$99+/month。

### 風險

Compression 可能丟失 identifier、error detail 或 security-relevant context；不同 coding agent 的 transport/protocol 快速變動；provider caching 可能降低節省幅度。產品必須把 correctness gate 放在 savings 前面。

### 結論

Paritok 證明「coding-agent context cost」已經可以單獨形成產品與價格。對 Solopreneur 更好的 wedge 是 context observability + policy + reversible optimization，而不是直接與 open-source compressor 做模型競賽。

## English

Paritok launched on Product Hunt on 2026-08-11 and ranked #3 during this run. It is a drop-in compression gateway for coding agents, reducing repeated tool schemas, file/tool outputs, and stale history while exposing a recovery path for exact originals.

Public monetization is clear: self-hosting is free under Apache-2.0 and hosted GPU processing is priced at US$0.30 per 1M processed tokens after the launch promotion. The upstream project reports substantial token reduction, but its benchmark numbers are treated as self-reported, not independent proof.

The commercial-open-source gate passes for repository code and the Paritok-4B-v1 adapter. The Qwen3-4B-Instruct-2507 base model is also marked Apache-2.0. The 45K training trajectories are **not** ranked as a reusable data/trajectory asset because an independently licensed public dataset was not verified.

The stronger Solopreneur wedge is **Coding-Agent Context Cost Guard**: observe context composition and cost first, detect waste, then offer guarded reversible compression with identifier checks, fallback, and CI policy. Validate against at least 100 sessions and 20 fixed coding tasks before selling optimization claims.
