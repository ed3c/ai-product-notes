# HarnessRouter Community Edition｜2026-08-17

## 繁體中文

### 產品與公司概況
HarnessRouter Community Edition 於 2026-08-16 在 Product Hunt 發布並取得當日 #2。產品把 Codex、Claude Code、Hermes 等 agent harness 包在一個共同 Agent API 後面，Community Edition 可自行部署在單一 Docker container；Gateway、Runner、Console、SQLite state 與 workspace files 留在使用者控制的 infrastructure。Hosted HarnessRouter Cloud 則提供 managed sandboxing、concurrency/isolation、execution tracing 與 harness × model comparison。

### 目標客群與痛點
目標客群是把 coding/research agents 嵌入產品的 developer-tool teams、AI SaaS 與 internal platform teams。核心痛點不是模型 API，而是每個 harness 都有不同的 session lifecycle、streaming、file/artifact semantics、cancel/retry/failure behavior 與 provider integration。若直接綁死單一 harness，切換 Codex / Claude Code / Hermes 會重寫 backend 並重新驗證 production behavior。

### 商業模式與定價
Community Edition 免費開源。Managed Cloud 公開方案為 Developer US$20/month（500 credits）、Production US$100/month（3,000 credits）、Scale US$200/month（10,000 credits），Enterprise custom。Credits 在 task execution 時消耗。這提供直接 WTP evidence，但 Community Edition 本身主要是 adoption / distribution wedge。

### 技術與營運門檻
Unified Harness Protocol（UHP）提供 versioned HTTP contract、OpenAPI 3.1、JSON Schema 2020-12 與 52 runnable conformance checks。這降低 protocol-level portability 成本，但不等於 task-level behavioral parity。Repository README 也指出第三方 agent CLIs 有不同授權：Codex 為 Apache-2.0；Claude Code 受 Anthropic terms 約束；Hermes upstream 在該 README 描述為沒有可重新散布的明確 license，因此 container 在 first-run 才由使用者自行安裝。部署上需要處理 default-password、network exposure、provider keys 與 sandbox boundary。

### 競爭與 Market Gap
直接競品包含自建 adapter layer、agent SDK/framework 的 provider abstraction，以及其他 agent runtime/control-plane。HarnessRouter 的差異化在於把「harness」而不是只有「model」視為可切換 backend，並提供公開 protocol + conformance。尚未被完全解決的 gap 是：**protocol conformance 不代表同一 business task 換 harness 後仍產生等價 artifact、tool behavior、cost、latency 與 failure semantics**。

### Solopreneur MVP：Harness Switch Regression CI
不要複製 HarnessRouter。MVP 做 external compatibility/equivalence layer：

`golden task → Harness A / Harness B → session/tool/file/artifact trace → semantic diff → cost/latency/failure comparison → switch/canary/hold receipt`

第一版支援 Codex / Claude Code / Hermes 其中兩個，20–30 個 deterministic fixtures，輸出 GitHub PR report。建議收費 US$49–199/repo/month，agency/platform tier US$399+。

### 兩週驗證計畫
1. 找 5 個已把 coding agents 嵌入產品的 teams。
2. 每家收集 20 個 redacted golden tasks。
3. 在兩個 harness 上 replay，量測 task success、artifact parity、tool/file semantics、latency、token/provider cost、retry/failure differences。
4. 通過門檻：至少 3 家發現原本不知道的 migration regression；至少 2 家接受 US$99/month paid pilot。

### 主要風險與結論
最大風險是 UHP/conformance suite 本身快速補足更多 parity tests，以及 agent harness protocols 高速變化。Moat 應累積在 real-world cross-harness fixtures、historical regression corpus 與 migration receipts，而不是 adapter code。

**結論：VALIDATE。** HarnessRouter 已證明 harness portability 正在變成獨立 infrastructure category；更適合 Solopreneur 的切入點是「switch 是否安全」而不是再做一個 router。

## English

### Product and market
HarnessRouter Community Edition launched on Product Hunt on August 16, 2026 and ranked #2 for the day. It exposes Codex, Claude Code, Hermes and other supported agent harnesses behind one Agent API. Community Edition runs Gateway, Runner and Console in one Docker container with user-controlled keys, state and files; HarnessRouter Cloud sells managed sandboxing, isolation, tracing and harness × model comparison.

### Business model and WTP
Community Edition is free/open source. Public managed plans are US$20/month Developer, US$100/month Production, US$200/month Scale, plus custom Enterprise. This is direct payment evidence for the managed layer, while the open-source runtime is the adoption wedge.

### Technical and license assessment
UHP provides a versioned HTTP contract, OpenAPI 3.1, JSON Schema 2020-12 and 52 runnable conformance checks. Repository code at commit `902c2c2146fb4e4ce5f2c666836a0c203ed706a1` is Apache-2.0. That license does not extend to every upstream harness CLI: the project documentation explicitly treats Claude Code and Hermes licensing separately from Codex.

### Solopreneur gap
The stronger wedge is **Harness Switch Regression CI**: replay production-representative golden tasks across harnesses and compare task success, artifacts, tool/file semantics, failure behavior, latency and cost. Protocol compatibility is necessary but does not prove behavioral equivalence.

### Two-week validation
Test five teams, 20 tasks each, across two harnesses. Continue only if at least three teams discover an unknown migration regression and two accept a US$99/month pilot.

**Decision: VALIDATE.** Build the migration/equivalence evidence layer, not another harness router.
