### 目標客群與痛點

目標客群是 agent-platform engineers、coding-agent builders、AI infrastructure teams，以及希望替換 model/tool/storage/UI 而不重寫整個 agent runtime 的團隊。核心痛點不是「缺一個 agent loop」，而是 production harness 常把 model adapter、tool registry、memory/session、sandbox、approval 與 UI 綁死在同一 framework，導致 provider migration、policy changes、runtime experiments 和 rollback 成本很高。

### 技術差異化

DeepSeek Harness 以 Cordis plugin tree 組裝 runtime。官方 architecture 明確把 model adapter、tool registry、session log、agent loop、sandbox/approval policy、credentials、telemetry 等都視為可替換 capability。Durable `SessionEvent` log 也是 model-visible context、fork/resume、replay 與 telemetry 的 source of truth。這讓它更接近「agent operating substrate」而不是單一 agent app。

值得注意的 production contract：`Model-visible means logged`。任何進入 model request 的資料都必須能從 durable log 重建，這對 replay、audit、training-data extraction 與 regression testing 很有價值。

### 商業模式與 WTP

目前 repository 與 npm developer-preview runtime 為免費 open source，沒有可驗證的直接 subscription WTP，因此 WTP 評分保持保守。商業價值主要來自：

1. plugin ecosystem 與企業 integration；
2. managed runtime / governance / observability 的上層服務可能性；
3. 降低 agent stack provider lock-in；
4. 讓 plugin compatibility、regression、security certification 成為獨立付費層。

### License / open asset 判定

Repository code 的 primary `LICENSE` 為 MIT，允許 commercial use、修改、再散布與 sublicensing，且不要求採用者的衍生產品全面開源。因此 repository code 可進 `RANK.md` 的 `PASS`。這個判定不延伸到外接 model weights、datasets、third-party plugins 或 trajectories；它們必須各自驗證。

### Market Gap 與 Solopreneur MVP

最適合 Solopreneur 的 wedge 不是 fork 整個 harness，而是 **Harness Plugin Compatibility Lab**：

`plugin/version → boot profile → golden agent tasks → tool/session/policy assertions → compatibility report`

第一版只支援 DeepSeek Harness plugin + MCP/ACP-facing adapters，對每個 runtime release 自動 replay plugin fixtures，檢查 schema drift、event contract、permissions、session replay 與 breaking changes。

建議收費：US$49–199/plugin/month；企業 private compatibility matrix US$499+ / month。

### 兩週驗證

- 找 10 個公開或內部 plugin/adapters。
- 建 30 個 golden compatibility fixtures。
- 對目前 rc 與前一個 rc 做 replay，要求能捕捉真實 breaking changes。
- 免費替 5 個 plugin maintainers 產生 compatibility report。
- 通過門檻：至少 3 個 maintainers 認為報告能取代人工 release testing，且 2 個願意付 US$99/month。

### 主要風險與結論

最大風險是 upstream 明確標示 developer preview，compatibility-breaking changes 會很頻繁；另一方面這也正是 compatibility product 的需求來源。另一風險是 DeepSeek 未來自己提供官方 conformance suite。短期最值得累積的資產不是 UI，而是跨版本 fixtures、plugin failure taxonomy 與 replay evidence。

結論：**高技術價值、高 ecosystem option value，但直接 WTP 尚未驗證；適合當 open implementation asset 與 compatibility-testing business wedge。**

## English

### Product and sources

DeepSeek Harness appeared on Product Hunt's August 14, 2026 launch board as a composable agent harness where models, tools, prompts, storage, the agent loop, and UI are plugins. The primary repository is `deepseek-ai/deepseek-harness`, verified at commit `47f943859bef60e4160492346772ded9b24f765a` under MIT.

### Customer and pain

The target buyer is an agent-platform or coding-agent team that needs to swap models, tools, persistence, sandbox policy, approval flows, or UI without rewriting a monolithic runtime. The key problem is harness coupling and the cost of provider/runtime migration.

### Differentiation

Cordis provides a plugin tree with reversible effects and swappable capability seams. The append-only session event log is the durable source for model-visible context, replay, fork/resume, telemetry, and recovery. The architectural contract that model-visible input must be reconstructable from the log is especially useful for audit and regression testing.

### Business and WTP

The runtime is currently open source and in developer preview, so direct paid WTP is not yet proven. The stronger monetization opportunity is around compatibility certification, managed governance, observability, and enterprise integration rather than charging for the core loop.

### Solopreneur MVP

Build a Harness Plugin Compatibility Lab that replays golden plugin fixtures across runtime releases and checks event contracts, schemas, permissions, replay behavior, and breaking changes. Start at US$49–199 per plugin per month.

### Two-week validation

Run 30 fixtures across 10 plugins/adapters and two runtime versions, deliver free compatibility reports to five maintainers, and continue only if at least two accept a US$99/month paid pilot.

### Risks and conclusion

The upstream project explicitly warns that compatibility-breaking changes will occur during developer preview. That increases maintenance risk but also creates the need for regression evidence. The durable moat for a small vendor would be the fixture corpus and failure taxonomy, not a wrapper UI.
