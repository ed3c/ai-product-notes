## 繁體中文

### 產品概況

Mindcase 提供 agent-oriented web data APIs，把 LinkedIn、Google Maps、Amazon、Instagram、TikTok、Reddit 等公開 web surfaces 封裝成結構化、按結果計價的 APIs。官方目前顯示 70+ APIs、25+ sources，並以「one API per task」降低 agent 開發者自己維護 scraper、proxy、anti-bot 與 data normalization 的成本。

### Target customer 與痛點

- AI sales / recruiting / market intelligence / commerce agents。
- 痛點不是「能不能抓網頁」，而是不同 source 的 schema、rate limit、block、proxy、retry 與變更成本。
- Agent 需要 predictable structured output，而不是一堆 brittle browser automation。

### 商業模式與定價

Mindcase 採 per-result usage pricing。官方目前可見例子包括：LinkedIn employee/profile 約 **US$0.004/result**、Google Maps places 約 US$0.004/place、Amazon products 約 US$0.0015/product、Reddit posts 約 US$0.0001/result 等；不同頁面與 API 可能呈現不同批量價格，因此 production procurement 應以 checkout/API console 即時價格為準。

這是直接 WTP evidence：客戶為「可用的 structured result」而不是 proxy/GPU/HTTP request 買單。毛利取決於 upstream acquisition cost、block rate 與維護成本；熱門平台若 policy/anti-bot 改變，毛利會快速波動。

### Market Gap 與差異化

競品包括 Apify、Bright Data、SerpAPI、RapidAPI data providers、browser agents 與自建 scrapers。Mindcase 的差異化是更 agent-native、task-specific、per-result packaging，但長期 moat 不能只靠 scraper；需要 data quality、freshness、schema stability、compliance/provenance 與 source-change adaptation。

### Solopreneur MVP

更好的 wedge 是 **Agent Data Rights & Provenance Receipt**，而不是再做一個 scraping platform：

1. 對每個 retrieved field 保存 source URL、timestamp、extractor/version 與 transformation lineage；
2. 標示可能包含 PII / copyrighted text / platform-restricted data；
3. source policy 或 schema 變更時建立 impact diff；
4. 支援 delete / re-fetch / re-derive receipt；
5. 不提供法律結論，只提供 evidence 與 workflow controls。

### 兩週驗證

- 鎖定一個 vertical，例如 B2B lead enrichment agencies。
- 找 5 家每天使用 web-data APIs 的團隊。
- 追蹤 10 個 data sources、1,000 筆 records 的 source/provenance chain。
- Gate：至少 3 家發現原本無法回答的 source-rights/freshness 問題，並取得 **2 個 US$99–199/month pilots**。

### 主要風險

Platform Terms of Service、data rights、PII、anti-bot changes、source blocking、資料新鮮度，以及客戶可能把 provenance 當成法律保證。產品應定位為 evidence/control plane，不是 legal advice。

### 結論

Mindcase 驗證了 agent-ready web data 的 usage WTP，但 scraping 本身競爭密度高。更有機會的 Solo layer 是 **來源、權利、freshness 與 reprocessing 的可稽核 provenance**。

## English

Mindcase packages web data from many public sources into task-specific APIs for agents. Its value proposition is predictable structured output without each customer operating scraper, proxy, retry, and schema-normalization infrastructure.

The pricing model is usage-based per delivered result, with public examples around fractions of a cent for LinkedIn, Google Maps, Amazon, Reddit, and other source-specific tasks. That is direct WTP evidence, but upstream platform changes can materially change acquisition cost and margin.

The more defensible Solopreneur opportunity is an **Agent Data Rights & Provenance Receipt**: capture source URL, timestamp, extractor version, transformations, sensitive-data flags, policy/schema changes, and delete/re-fetch lineage. Validate it with B2B enrichment teams rather than building a general scraper.
