## 繁體中文

### 產品與公司概況

OneCLI 把「每位員工一個 agent」做成 team harness：每個 agent 有獨立 sandbox、memory、skills、schedule 與 identity，所有 outbound requests 經由 gateway；gateway 在 request-time 注入 credential、執行 host/path policy、rate limit 與 human approval。其核心價值不是再做一個 agent，而是把 credential、permission、audit 與 team lifecycle 從 prompt layer 移到可強制執行的 runtime layer。

2026-08-21 的 Product Hunt launch 將定位進一步推向「secured, sandboxed personal agent for every employee」。官方 pricing 顯示 Free 為 3 users / 3 agents；Team 為 **US$199/month、10 users / 20 agents**；Scale 為 **US$499/month、25 users / 50 agents**；Enterprise custom。Scale 另提供 managed self-hosting in customer VPC，官方列價 **US$1,499/month**。這是明確 B2B WTP evidence。

### Target customer 與核心痛點

- 已在團隊內部署 Claude Code、Codex、Cursor、Hermes、OpenCode 或 autonomous workflows 的 5–100 人 engineering teams。
- 真實痛點是 raw secrets、OAuth scope、repo permissions、destructive actions 與多人 agent governance，不是 model quality。
- Prompt-based guardrail 不足以當 security boundary；policy 必須在 agent/LLM 外部的 execution choke point 強制執行。

### 商業模式、WTP 與毛利空間

OneCLI 採 open-core + hosted/team subscription。Team / Scale 的固定 agent-count pricing 讓收入直接對應「可治理 agent 數量」而非 token markup。對 software layer 而言毛利潛力高，但 enterprise VPC、security review、support 與 incident liability 會拉高營運成本。

WTP 評為 9/10：官方已有 US$199–499/month 的 self-serve/team packaging，並把 approvals、audit retention、policy rules、SSO/SAML、VPC/on-prem 等高價值 control-plane features 放在付費梯度中。Funding 只給 4/10：能確認 YC backing，但本輪沒有把未披露的融資金額當成 funding evidence。Traction 7/10：官方 pricing 頁列出多家 trusted-by logos，另有開源 adoption signal，但仍以 vendor-reported evidence 為主。

### 競爭與 Market Gap

直接/鄰近競品包括 secrets managers、HashiCorp Vault / Infisical 類 credential infrastructure、agent gateways、MCP security layers、enterprise agent runtimes。真正 gap 是 **agent identity + least privilege + credential injection + approval + durable audit** 的跨-harness contract。

### Solopreneur MVP

不建議複製完整 OneCLI。更窄的產品應是 **Agent Credential Boundary Regression Gate**，並視為既有 `Agent Secret Egress Gateway` thesis 的強驗證，而不是在 Solopreneur Top 100 建立重複項目。

MVP：
1. snapshot agent → credential / repo / tool / endpoint scopes；
2. 定義 30–50 個 allowed / denied synthetic actions；
3. 每次 policy、identity provider、harness 或 connector 版本改動後 replay；
4. 輸出 `scope-expanded / approval-bypassed / denial-regressed / safe` receipt；
5. destructive actions 永遠需要 explicit human approval。

### 兩週驗證

- 找 5 個已使用多 agent / MCP / coding-agent 的小團隊。
- 每隊匯入 10–20 個真實 permission policies，建立 30 個 fixtures。
- 回放 connector token rotation、repo scope change、agent migration、provider fallback 與 policy edit。
- Gate：抓到至少 5 個 material permission regressions、false-positive <10%，並取得 **2 個 US$199/month paid pilots**。

### 主要風險

Security liability、TLS interception / credential handling complexity、IdP 與 SaaS API 差異，以及 OneCLI / cloud providers 原生加入完整 regression suite。產品不能宣稱「絕對安全」；應出售可重現 policy evidence、least-privilege regression 與 audit receipts。

### 結論

OneCLI 證明 agent security 的付費點正從 secret storage 上升到 team-level runtime governance。Solopreneur 最好的 wedge 不是 vault，而是 **permission change 之後仍然符合原本 security contract 的可驗證證據**。

## English

### Product and company

OneCLI turns “one agent per employee” into a governed team harness. Each agent can have an isolated sandbox, memory, skills, schedule, and identity. Outbound requests pass through a gateway that injects credentials at request time and enforces host/path policies, rate limits, approvals, and audit controls outside the model.

Its current public pricing provides direct willingness-to-pay evidence: Free supports 3 users / 3 agents; Team is **US$199/month for 10 users / 20 agents**; Scale is **US$499/month for 25 users / 50 agents**; Enterprise is custom. The Scale plan also lists managed customer-VPC self-hosting at **US$1,499/month**.

### Market gap

The high-value problem is not another agent loop. It is a portable contract for **agent identity, least privilege, credential injection, approval, and durable audit** across coding agents, autonomous workflows, and changing connectors.

### Solopreneur wedge

Build an **Agent Credential Boundary Regression Gate** rather than a full agent platform. Snapshot effective permissions, replay hidden allow/deny fixtures after policy or connector changes, and issue a decision receipt showing whether a change widened scope, bypassed approval, or changed denial behavior. This maps to the existing `Agent Secret Egress Gateway` opportunity and therefore does not create a duplicate Solopreneur row.

### Two-week validation

Use five design partners, 30 fixtures per team, and replay real policy/connector changes. Continue only if the system finds at least five material permission regressions with <10% false positives and closes two US$199/month pilots.
