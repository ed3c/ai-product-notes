## 繁體中文

### 產品與公司概況
Tines 3B 是 Tines 的 AI-native workflow platform。Product Hunt 在本輪監控的 launch board 將 Tines 3B 排在 #1。產品把 agent、app 與 automation 放進受控的 workflow runtime，而不是只提供 prompt builder。

### 目標客群與痛點
客群是 IT / security / operations teams，以及讓非工程師建立 internal agents 的企業。主要痛點是 generated code / AI builder 若直接看到 SaaS credentials，會把 secret exposure、prompt injection 與 excessive permissions 變成 production incident。

### 商業模式與定價
Tines 3B 使用 platform license model；Explore 是免費版本。公開頁面沒有標準 enterprise price，因此不能推測精確 ACV。Tines 2025 年完成 US$125M Series C，當時估值 US$1.125B；官方同時披露每週執行超過 10 億 automated actions、約三分之二客戶使用其 AI features。

### WTP 證據
企業級 platform licensing、既有 customer scale 與 Series C 是強 WTP / market-validation signal。Tines 3B 官方描述 credential 由 transparent runtime proxy 注入，secret 不暴露給 builder、AI 或 source code；workflow step isolated execution、monitoring、auditability、RBAC 與 version control 形成可信的 security wedge。

### 競爭與 Market Gap
競爭包含 n8n、Zapier、Workato、agent runtimes、secret managers、policy engines。Gap 在於多數 SMB agent stack 把「connector secret」與「agent execution」混在一起：agent 看得到 API key 或 OAuth token，且缺乏 per-action policy、approval 與 egress audit。

### 技術與營運門檻
核心技術是 OAuth/OIDC credential broker、runtime injection proxy、connector allowlist、network egress policy、short-lived credentials、audit ledger、approval gate。營運門檻是 security liability、integration maintenance 與客戶 trust。

### Solopreneur MVP：Agent Secret Egress Gateway
先做很窄的 security proxy：
1. 支援 5–10 個高頻 SaaS connectors。
2. Agent 只取得 opaque capability handle，不取得 raw secret。
3. Runtime 代為注入 credential。
4. 每個 tool/action 有 scope、rate、approval policy。
5. 保存 immutable egress audit。

建議價格：US$99–299/month/team；managed / self-hosted tier US$499+。

### 兩週驗證計畫
鎖定使用 Claude Code/Codex/n8n/MCP 且有 production credentials 的 5 個小團隊。以 shadow mode 盤點現有 secret exposure，再替兩條 workflow 接入 proxy。通過門檻：至少找出 3 個實際 excessive-secret / overbroad-scope 問題，並取得 2 個 US$199/month pilot。

### 主要風險與結論
風險是 Vault/cloud secret managers、agent frameworks 或 SaaS providers 自己補齊 runtime secret injection。Moat 必須是 agent-specific capability policy + evidence，而不是另一個 secret vault。

## English

### Overview
Tines 3B is an AI-native workflow environment for agents, apps, and automations. Its strongest signal is not generic automation; it is the security architecture around isolated execution, runtime credential injection, monitoring, and auditability.

### Customer, pain, and monetization
The buyer is an IT/security/operations team deploying AI-generated workflows. Tines uses a platform-license model with a free Explore edition. Existing scale and its prior US$125M Series C provide strong market validation.

### Market gap
A smaller product can focus on the gap between agents and SaaS credentials. Many agent stacks still expose long-lived credentials too directly to generated code or broad tool scopes.

### Solopreneur MVP
Build **Agent Secret Egress Gateway**: opaque capability handles, runtime credential injection, per-action scopes, approvals, egress policies, and an immutable audit trail for a small connector set.

### Two-week validation
Audit five agent teams in shadow mode and proxy two production workflows. Pass if three real secret/scope risks are found and two teams accept a US$199/month pilot.

### Risks
Cloud secret managers and agent frameworks may absorb the feature. The defensible layer is agent-specific policy and evidence, not generic secret storage.
