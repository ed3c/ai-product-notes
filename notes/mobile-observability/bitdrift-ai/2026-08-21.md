### 產品與公司概況
bitdrift 是 mobile observability platform，核心架構使用 on-device bounded ring buffer 與 real-time control plane，讓團隊不用等待 App Store / Play Store release 就能改變 telemetry collection。2026-08-20 的 Product Hunt signal 進一步把產品定位往 agentic mobile observability 推進：agents 可以查詢 production mobile behavior 並協助 investigation / action。

### 目標客群與痛點
Target customer 是 iOS / Android / React Native / Flutter teams。Mobile production bug 的難點是 release cadence 慢、telemetry 通常事前沒收、session context 分散，且 server-centric observability 不足以重建 user journey。

### 商業模式、定價與 WTP
官方 Free tier 為 US$0，包含 5 users、100K crash reports/month、50K active applications/month、14-day retention 與 3 workflows；Enterprise 為 contact sales，加入 unlimited users/workflows、session replay、SSO、RBAC、BYOB 與 dedicated support，依 monthly active applications 計價且不收 overage。WTP 評 8/10。官方 Lyft case study稱 mobile MTTR 降低超過 80%；其他 named cases 包含 Reddit、Bluesky、ThredUp、Favor 等。這些主要是 vendor-hosted evidence，但已有明確 enterprise packaging 與 production usage。

### 競爭與 Market Gap
Sentry、Datadog、Embrace、Bugsnag 等已涵蓋 mobile observability。bitdrift 的 differentiation 是 unsampled/on-device telemetry、remote capture reconfiguration 與 mobile-first investigation。新的 gap 是 agent 能提出 investigation/action 後，誰來證明該 action 有 evidence、權限正確、可 rollback，而且沒有把 production incident 擴大。

### 技術與營運門檻
需要 privacy-safe session reconstruction、mobile resource constraints、on-device ring buffer、remote config、identity/session stitching、incident correlation、RBAC、approval、rollback 與 tamper-evident audit。Mobile SDK 本身還必須證明不造成 crash、hang 或 performance regression。

### Solopreneur MVP — Mobile Agent Incident Action Guard
不做 observability backend。接 Sentry/bitdrift/OTel incident events，讓 agent 在 shadow mode 產生：`hypothesis → evidence links → proposed action → expected impact → rollback plan`。只有通過 policy 與 human approval 才能觸發 remote config / feature flag / rollback 類 action，並保存 before/after incident receipt。

### 兩週驗證計畫
1. 找 5 個 mobile teams，每家匯入 20 個歷史 incidents。
2. 重建 incident context，讓 agent 只做 shadow-mode recommendation。
3. 量測 evidence completeness、false diagnosis、unsafe action、time-to-triage。
4. Gate：至少 3 teams 的 triage time 降低 30%，且抓到 ≥5 個缺少 rollback/permission/evidence 的高風險 action，取得 2 個 US$199/month pilots。

主要風險是 production action liability、mobile PII、vendor API scope 與 incident ground truth。可收費的 wedge 是 evidence + approval + rollback layer，而不是再做一套 telemetry ingestion。

## English

### Product and WTP
bitdrift is a mobile-first observability platform built around an on-device bounded ring buffer and remotely changeable collection rules. Its free tier includes five users, 100K monthly crash reports and 50K monthly active applications; Enterprise adds session replay, SSO, RBAC, BYOB, unlimited workflows, and support. Pricing scales by monthly active applications with no overages. A vendor-hosted Lyft case study reports more than 80% lower mobile MTTR.

### Gap
The emerging risk is agentic production investigation: once an agent can query rich mobile telemetry and propose actions, teams need evidence quality, permission checks, human approval, and rollback proof.

### Solopreneur MVP
Build a Mobile Agent Incident Action Guard that sits above existing observability tools. Run agents in shadow mode, require evidence links and rollback plans, enforce policy/approval, and retain before/after incident receipts.

### Two-week validation
Replay 20 historical incidents for five mobile teams. Pass if triage time falls by at least 30% for three teams, the system finds at least five unsafe or under-evidenced proposed actions, and two teams accept a US$199/month pilot.

### Risks
Production liability, privacy, mobile PII, vendor API scope, and incident-ground-truth quality.
