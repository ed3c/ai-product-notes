# Notes Index / 筆記索引

## 繁體中文
深度筆記依產品能力與商業問題分類，不依日期平鋪。相同產品若已有 canonical path，後續研究優先更新既有筆記或在同一產品目錄新增日期版本，不重複建立無關副本。

## English
Deep notes are organized by capability/business category. Reuse the canonical product path when possible; add a dated revision under the same product directory when evidence materially changes.
