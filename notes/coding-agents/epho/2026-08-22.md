## 繁體中文

### 產品概況

Epho 把 Claude Code、Codex、OpenCode 類 coding agents 封裝成 cloud `agents-as-an-API`：一個 HTTP request 觸發 sandbox、clone repositories、配置 harness / MCP servers、處理 provider/sandbox fallback、stream events、attachments 與 output files。Founder 明確表示這是從自家 production agent 的 infrastructure pain 拆出的獨立 primitive。

### Target customer 與痛點

- 想把 coding agents 嵌入 SaaS / internal automation，但不想自己維護 sandbox fleet 的小型 AI teams。
- 痛點包含 sandbox image/config、agent-specific integration、provider fallback、repo auth、streaming、artifact collection、retry 與 cleanup。

### 商業模式與定價

公開產品索引顯示 usage-based pricing：default instance 約 **US$0.0000438/sec**，並列出約 US$0.0000164 / vCPU-second 與 US$10 starting credit。這些價格目前主要來自 launch-directory capture，應在正式採購前再以 Epho checkout/docs 驗證。

WTP 評為 7/10：managed sandbox + harness abstraction 有直接工程成本替代價值，但目前缺少成熟 customer traction、SLA 與 enterprise evidence。

### Market Gap

競爭包括 Modal/Daytona/E2B 類 sandbox infra、managed coding-agent runtimes、self-hosted sandbox-agent projects，以及 cloud providers。Epho 的差異化是 higher-level `coding-agent execution API`，而不是裸 VM/sandbox。

真正的 gap 在 **fallback correctness**：一個 run 從 sandbox/provider A retry 到 B 時，repo/MCP/network credentials、tool permissions、filesystem state、event semantics 與 artifacts 是否保持同一 contract？

### Solopreneur MVP

不建議再造通用 agent sandbox。更窄的 wedge 是 **Agent Runtime Fallback Parity Verifier**，可視為既有 `Harness Switch Regression CI` / `Agent Secret Egress Gateway` thesis 的實作驗證：

1. 定義 run manifest：repo scopes、MCP scopes、network allowlist、provider/model、sandbox image；
2. 同一 fixture 在 primary / fallback runtimes dual-run；
3. 比對 effective permission、filesystem diff、tool calls、artifacts、exit semantics；
4. 若 fallback scope 變寬或 artifact contract 改變，直接 hold；
5. 輸出 migration/fallback receipt。

### 兩週驗證

- 5 個 agent-product teams，每隊 10–20 representative runs。
- 模擬 sandbox unavailable、provider rate limit、expired repo token、MCP failure。
- Gate：找到至少 5 個 fallback-specific regressions / permission mismatches，取得 2 個 US$99–199/month pilots。

### 主要風險

Cloud-sandbox security、source-code confidentiality、credential handling、provider-specific token terms、cross-provider nondeterminism、logs/artifact retention。任何涉及 write-capable repository tokens 的 workflow 都必須採最小權限與短期 credentials。

### 結論

Epho 顯示 coding-agent runtime 正被抽象成 API；可收費的下一層不是「能跑 agent」，而是 **runtime/provider fallback 後仍維持相同權限與行為 contract 的 evidence**。

## English

Epho exposes coding agents such as Claude Code, Codex, and OpenCode as a cloud API. It handles sandbox setup, repository cloning, harness integration, retries, fallbacks, event streaming, and artifacts so teams do not have to operate the full execution layer themselves.

The strongest Solo opportunity is not another managed sandbox. It is an **Agent Runtime Fallback Parity Verifier** that proves a retry or migration preserves repository/MCP/network scope, filesystem semantics, artifacts, and execution behavior. This overlaps existing harness-switch and secret-egress opportunities, so it should validate those rows rather than create a duplicate concept.
