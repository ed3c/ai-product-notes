### 客群與痛點

核心客群是開發 MCP、CLI、SDK、coding-agent integration 或企業 agent workflow 的產品團隊。傳統 benchmark 常測模型能力，卻不能回答「agent 是否真的能發現並正確使用我的產品介面」。實際失敗常來自 tool discovery、schema friction、retry loop、token bloat、環境依賴與版本漂移。

### 商業模式與 WTP

Oqoqo 採 usage-based SaaS：Free 100 runs/month；Pro US$20/month 含 300 runs；Ultra US$60/month 含 1,000 runs；另有 US$5 起的 top-up，model inference 由客戶自己的 API key / subscription 支付。這是直接 WTP 證據，不只是 waitlist。

內部 Best 評分：WTP 8 / Funding Scale 3 / User Traction 7 / Market Gap Moat 9，Composite 6.75。

### 差異化與 Gap

產品不是單純 LLM-as-judge dashboard。它把 realistic sandbox、custom task set、private benchmark、multi-trial agent run、full trajectory、cost/token telemetry 與 MCP/CLI/SDK regression 放在同一個 experiment workflow。Gap 在於「agent-facing product surface」仍缺少像 browser/app regression testing 一樣穩定的 CI discipline。

競爭包含 Braintrust、LangSmith、Promptfoo、Prefactor、Openlayer、Mechanize 等。Oqoqo 的 wedge 是 product-surface evaluation，而非只評 final answer 或 production trace。

### 技術與營運門檻

需要可重置 sandbox、deterministic fixture、agent harness adapters、multi-trial statistical aggregation、trajectory capture、rubric calibration、artifact retention 與 CI integration。主要營運成本來自 sandbox compute、第三方 model usage、benchmark maintenance 與 flaky-task diagnosis。

### Solopreneur MVP — Agent Interface Regression CI

Target: developer-tool startups exposing MCP / CLI / SDK.

MVP：
1. GitHub App 監聽 PR 或 release。
2. 維護 20–50 個 agent-facing golden tasks。
3. 在 disposable container 執行 Claude Code / Codex-compatible harness。
4. 記錄 tool calls、retries、success rubric、token/cost。
5. 只有 regression 才在 PR 留 comment；附可 replay evidence。

建議收費：US$49–199/repo/month，額外 run usage 計價；agency / multi-repo tier US$399+。

### 兩週驗證

- 選 1 個狹窄 vertical：MCP server / developer API。
- 對 5 個 active repositories 回放最近 10–20 次 releases。
- 建立至少 30 個 agent interaction cases。
- 成功門檻：抓到至少 2 個真實 regression / friction，其中 1 個被 maintainer 接受；至少 2 家願意支付 US$99/month pilot。

### 主要風險

最大的風險是 flaky/non-deterministic eval 造成 alert fatigue；第二是 sandbox security 與 customer private code；第三是大型 eval platform 向 product-surface regression 擴張。Moat 應放在高品質 domain-specific tasks、failure taxonomy、replay evidence 與 historical regression data，而不是 dashboard UI。

### 結論

這是本日最強 Solopreneur signal 之一。WTP 已由公開 pricing 驗證，MVP 可在不訓練 foundation model 的前提下完成。最好的切入點不是複製完整 Oqoqo，而是聚焦 MCP/CLI/SDK 的 agent-interface regression CI。

## English

### Product and signal

Oqoqo launched on Product Hunt on 2026-08-11 and ranked #1 during this monitoring run. It provides realistic agent evaluation environments, custom/private benchmarks, full trajectories, and regression testing for agent-facing product surfaces.

### Customer and pain

The core buyer is a developer-tool or AI-product team exposing MCP, CLI, SDK, or agent workflows. Traditional model benchmarks do not tell the team whether agents can discover the product, choose the right tool, recover from interface friction, or complete real tasks after a release.

### Business model and WTP

Public pricing provides direct WTP evidence: Free includes 100 runs/month, Pro is US$20/month for 300 runs, and Ultra is US$60/month for 1,000 runs. Top-ups are available and model inference is paid separately through customer-owned credentials.

### Solopreneur wedge

The best narrow wedge is **Agent Interface Regression CI**: golden tasks for one developer surface, disposable environments, agent-run replay, tool-call and retry traces, token/cost measurement, and PR-level regression evidence.

### Two-week validation

Replay recent releases across five MCP/API projects. Build 30 cases. Continue only if the system catches at least two real regressions/frictions and two teams accept a US$99/month pilot.

### Risk

Nondeterministic agents can create noisy tests. Security boundaries for private code are non-negotiable. The durable advantage must come from task quality, failure taxonomy, reproducibility, and accumulated regression history.
