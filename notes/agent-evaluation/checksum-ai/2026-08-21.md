# Checksum AI｜2026-08-21

## 繁體中文

### 產品與公司概況
Checksum AI 是 continuous quality / AI-native testing platform。它把 E2E、API 與 CI testing 放在 always-on loop：分析 code/application、產生 tests、在 CI 或 sandbox 執行、區分 product bug 與 stale test，再把 test healing 以 reviewable change 回到 repository。輸出是標準 Playwright code，tests 留在客戶 repo，而不是 proprietary test format。

### 目標客群與痛點
Target customer 是大量使用 Cursor / Claude Code / Codex 或 vibe coding、PR volume 快速增加的 SaaS / engineering teams。Pain 是 code generation throughput 已上升，但 release verification、test maintenance、failure triage 與 hidden user-journey coverage 沒有同步擴張。

### 商業模式、定價與 WTP
Checksum 採 managed/demo-led B2B model；公開頁面可見 30-day trial，但本次沒有找到可安全引用的標準 self-serve dollar price，因此不猜定價。WTP 評 9/10，因為 vendor-hosted customer cases 報告 Clearpoint 約 US$500K annual testing savings、Reservamos 約 US$200K annual savings，以及多個 named enterprise / SaaS cases。這些是 vendor-hosted evidence，方向性強但不是獨立 audited ROI。

### 競爭與 Market Gap
競品包括 QA.tech、TestSprite、Qodo、Playwright-based agents 以及 coding agent 自己產 tests。Checksum 的 differentiation 是 continuous generate → run → triage → heal loop、production-aware context，以及 tests remain portable in the repo。Gap 仍在「驗證 AI 產生的 code 是否真的符合 user intent」，而不只「visible tests pass」。研究已指出 coding agents 可能 build to the test，因此 release gate 必須加入 hidden behavioral oracle、mechanical audit 與 negative/edge cases。

### 技術與營運門檻
需要 ephemeral environments、seeded test data、deterministic fixtures、browser/API execution、failure classification、flakiness control、test healing review、security isolation 與 secret handling。最大的產品風險是 auto-healing 把真正 product regression 誤判成 stale test。

### Solopreneur MVP — AI-Generated Code Release Gate
第一版不做 full QA platform。只鎖定 AI-generated PR：
`PR → change impact → hidden golden journeys → browser/API replay → mechanical contract audit → ship / hold receipt`。

每個 release receipt 要保留：code diff、test evidence、failed user journey、flakiness confidence、manual approval 與 model/agent version。這比「多產 tests」更接近付費 decision layer。

### 兩週驗證計畫
1. 找 5 家 agent-heavy SaaS，每家提供最近 20 個 PR。
2. 建 20–40 個 hidden user-journey fixtures，不暴露給 coding agent。
3. 比較既有 CI 與 release gate 找到的 defects。
4. Gate：找到至少 5 個 existing tests / review 沒抓到的 release risks、false-positive <10%，並取得 2 個 US$99–199/month pilots。

### 主要風險與結論
競爭密度高；GitHub、Playwright vendors、coding-agent vendors 都能向這層擴張。Moat 應放在 hidden production-representative fixture corpus、cross-agent regression history 與 decision receipts，而不是 test generation UI。

## English

### Product
Checksum is a continuous-quality platform that generates, runs, triages, and heals E2E/API tests. Tests remain standard Playwright code in the customer repository, reducing format lock-in.

### Customer and WTP
The buyer is an engineering team whose AI-generated code volume is growing faster than release verification capacity. Public standard pricing was not safely verifiable in this run. WTP is scored 9/10 based on multiple vendor-hosted customer ROI cases, including reported annual savings of roughly US$500K at Clearpoint and US$200K at Reservamos; these should be treated as directional vendor evidence, not audited ROI.

### Gap
The difficult problem is not test generation. It is independent proof that an AI-generated change still satisfies hidden user intent. Visible tests can become a target for coding agents, so a release gate needs hidden behavioral fixtures and mechanical audits.

### Solopreneur MVP
Build an AI-Generated Code Release Gate focused only on agent-authored PRs: impact analysis, hidden browser/API journeys, mechanical contracts, flakiness confidence, and a ship/hold receipt.

### Two-week validation
Replay 20 recent PRs across five AI-native SaaS teams. Pass if the system finds at least five material risks missed by existing CI/review, keeps false positives below 10%, and closes two US$99–199/month pilots.

### Risks
Crowded QA market, auto-heal masking real regressions, fixture maintenance, and secret/isolation burden. The defensible asset is a private hidden-oracle corpus plus cross-agent release history.
