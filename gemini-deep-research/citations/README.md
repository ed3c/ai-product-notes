# Citation Contract / 引用契約

## 繁體中文
每個 citation record 至少包含 `claim_id`, `source_title`, `source_url`, `event_date`, `published_at`, `retrieved_at`, `evidence_excerpt_or_paraphrase`, `confidence`。同一 claim 有衝突來源時全部保留並標記 conflict。

## English
Every citation record must include claim ID, source title/URL, event date, publication date, retrieval date, bounded evidence/paraphrase, and confidence. Preserve conflicting evidence instead of collapsing it.
