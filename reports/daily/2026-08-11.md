## 最值得執行的 3 個藍海方向

### A. Agent Interface Regression CI

**Target customer**：MCP / CLI / SDK / developer API startups。

**Pain**：release 後 agent 可能看得見 docs 卻無法正確調用 interface；人工 smoke test 無法捕捉 model × tool × environment 的 regression。

**MVP**：GitHub App + 30 golden tasks + disposable sandbox + Claude Code/Codex adapters + full trajectory + regression-only PR comments。

**Pricing**：US$49–199/repo/month；multi-repo / agency US$399+；額外 runs usage-based。

**Acquisition**：MCP registries、GitHub developer-tool repos、Claude Code/Codex communities、DevRel teams。

**Two-week validation**：5 個 active repos × 10–20 historical releases；至少 30 cases；抓到 >=2 個真實 regressions/frictions，至少 1 個被 maintainer 接受，且取得 2 個 US$99/mo pilots。

**Main risks**：nondeterminism / flaky tests、private-code sandbox security、large eval platforms 向下擴張。

### B. Continual Harness Drift & Rollback Guard

**Target customer**：允許 agents 永久修改 prompts / memory / skills / rules / tool permissions 的 agent-heavy software teams。

**Pain**：錯誤 refinement 會污染未來 sessions；reward hacking、secret leakage、permission widening 與 stale memory 變成 durable state。

**MVP**：state watcher → semantic mutation diff → static policy gate → before/after 20–50 golden tasks → human approve/reject → signed snapshot rollback。

**Pricing**：US$49–199/agent-project/month；team audit/policy tier US$299–999/month。

**Acquisition**：Prime Agent、Claude Code repo-memory、Codex CLI、LangGraph/Temporal agent teams。

**Two-week validation**：3 adapters；30 intentional bad refinements；dangerous mutation detection >=90%、false positive <10%、2 個 US$99/mo pilots。

**Main risks**：state schemas 快速變動、policy 差異、過度攔截降低 self-improvement value。

### C. Coding-Agent Context Cost Guard

**Target customer**：Claude Code / Codex / Cursor / MCP-heavy teams，尤其 token spend 已可量化的工程組織。

**Pain**：tool schemas、重複 file reads、stale history 與 large outputs 使 input cost 不透明；直接 compression 又可能丟 identifier 或 error detail。

**MVP**：OpenAI-compatible/local proxy，預設 observe-only；context attribution、waste detection、budget policy、可選 reversible compression、identifier checks、raw fallback、CI cost report。

**Pricing**：US$29–99/developer/month；team policy US$199–499/month。

**Acquisition**：Claude Code / Codex power users、MCP-heavy repos、AI coding agencies。

**Two-week validation**：10 devs / 100 sessions；先找到 >=20% duplicate/removable context，再對 20 fixed coding tasks A/B；median input cost -25% 以上、task-success regression <3%、2 個 team 願付 US$99+/month。

**Main risks**：compression correctness、provider caching 抵銷 savings、agent protocol churn。
