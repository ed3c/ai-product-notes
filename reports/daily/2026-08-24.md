### 最值得執行的藍海方向

#### A. Evidence-Bound Professional Work Product QA

**Target customer:** boutique eDiscovery providers、litigation support teams、legal ops、regulatory investigation consultancies。  
**Pain:** AI 已能生成 chronology / memo / investigation pack，但「有 citation」不等於每個 factual claim 真被來源支持，也不代表時間線、人物、金額與 contradictory evidence 一致。  
**MVP:** claim extraction → source-span requirement → citation entailment → timeline/entity consistency → contradictory-evidence search → professional review packet。先只做一個 workflow，例如 litigation chronology。  
**Pricing:** US$500–2,000 / matter，或 US$199–999/month/team。  
**Acquisition:** ILTA / eDiscovery communities、Relativity consultants、boutique legal-ops providers。  
**Two-week validation:** 30–50 個 synthetic / rights-cleared fixtures，植入 unsupported claim、wrong citation、timeline conflict、entity mismatch、omitted contradictory evidence；3–5 位 professionals blind review。Gate：material-defect recall ≥90%、false positive <10%，至少 1 個 US$1K paid pilot 或 2 個 US$299/month pilots。  
**Main risks:** professional liability、privilege/confidentiality、data residency；產品必須定位為 evidence QA / review acceleration，不是 legal advice。

#### B. Browser-Agent Policy Replay / Permission Regression Gate

**Target customer:** browser/computer-use agents、AG-UI/MCP agent platforms、internal AI coworker teams。  
**Pain:** browser selectors、session state、policy inputs、agent identity、snapshot references 或 gateway versions 改變後，原本 `allow / deny / ask approval` 的安全語義可能 silently drift。  
**MVP:** 30–50 hidden action fixtures → replay across agent/runtime versions → permission decision diff → audit completeness → human-takeover / rollback checks → ship/hold receipt。  
**Pricing:** US$99–399/month；initial security-policy fixture setup US$1K+。  
**Acquisition:** OpenBot / AG-UI / MCP / computer-use communities、AI automation agencies、security-sensitive internal agent teams。  
**Two-week validation:** 5 teams × 30 fixtures；至少找到 5 個 meaningful policy/permission regressions、false positive <10%，取得 2 個 paid pilots。  
**Main risks:** UI nondeterminism、security liability、upstream platforms adding native conformance suites。Moat 應累積在 cross-version security fixtures 與 historical decision receipts。

**Priority:** Evidence-Bound Professional Work Product QA → Browser-Agent Policy Replay / Permission Regression Gate. Alibaba 的資本訊號則繼續強化既有 Open-Model License Compliance / Model Upgrade Regression thesis，不需要再建重複 concept。
