## Three blue-ocean directions

### A. Routing Decision Ledger
Target customer: AI SaaS / agencies spending >= US$1K/month across multiple model providers.

Pain: routing rules change, but teams cannot prove whether quality, latency, cost and policy actually improved.

MVP: redacted production traces → current route vs candidate route → task quality / p95 latency / cost / fallback / policy checks → signed decision receipt.

Pricing: US$99–299/month; agency tier US$499+.

Acquisition: LiteLLM/OpenRouter/Langfuse communities, AI agencies, multi-model SaaS founders.

Two-week gate: five teams, 30–50 representative tasks each; at least three actionable findings and two US$199/month pilots.

Risk: OpenRouter and cloud vendors can absorb generic routing analytics. Defensibility must be customer-specific traces and historical decision evidence.

### B. Hosted Agent Migration Parity Verifier
Target customer: teams migrating managed/hosted agents across runtime versions or vendors.

Pain: API migration can succeed while identity, state, protocol, tool-call, retry or sandbox behavior silently changes.

MVP: old/new runtime dual replay → identity and permission diff → state/artifact comparison → tool-output and failure-semantic assertions → cutover/hold receipt.

Pricing: US$199–999 one-time migration audit plus US$49–199/month regression monitoring.

Acquisition: Microsoft Foundry users first, then LangGraph/managed-agent platforms and agencies.

Two-week gate: five real migrations, >=20 fixtures each; detect at least five semantic mismatches that configuration-only migration checks miss, and close two paid audits.

Risk: short-lived vendor-specific demand. The product must generalize to runtime/harness portability.

### C. Agent Security Release Evidence Pack
Target customer: small teams shipping MCP/coding/workflow agents with real tool permissions.

Pain: static prompt/security reviews do not prove that a release still blocks secret exfiltration, permission widening, prompt/tool injection and destructive actions.

MVP: capture agent identity/tool scope → 30–50 attack fixtures → policy replay → approval / egress / destructive-action assertions → release evidence.

Pricing: US$99–299/team/month or US$1K initial security-eval package.

Acquisition: MCP maintainers, agent agencies, coding-agent teams.

Two-week gate: five teams, >=3 real policy gaps, false positive <10%, two US$199/month pilots.

Risk: security liability and incumbent bundling; stay evidence-first and narrow rather than promising full protection.
