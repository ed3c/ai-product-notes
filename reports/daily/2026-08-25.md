## 最值得執行的三個藍海方向

### 1. AI Coding ROI & Roadmap Ledger

- Target customer: 每月 coding-AI spend ≥ US$5K，或至少 10 名 heavy AI-coding developers 的 engineering teams。
- Pain: CTO/CFO 無法把 AI spend 連到 roadmap value、rework、maintenance、quality。
- MVP: Git/PR + Linear/Jira + provider bills + CI/review/deploy，輸出 roadmap-level spend/outcome receipt；read-only，禁止 employee ranking。
- Pricing: **US$99–499/team/month** + **US$1K–3K** initial audit。
- Acquisition: GitHub/Linear/Cursor/Claude Code communities、DevEx、Engineering FinOps、CTO groups。
- Two-week test: 5 teams、4–8 weeks history、20–50 roadmap items；3 teams 發現 decision-changing insight + 2 個 US$199/month pilots 或 1 個 US$1K audit。
- Risks: causality、Goodhart、private code/roadmap/billing data、provider-native analytics。

### 2. Agent Fleet Lifecycle & Access Drift Auditor

- Target customer: 允許員工自行建立 agents 的 IT/security/platform teams。
- Pain: agent owner 離職、personal API key、stale OAuth scopes、未退休 agents、approval policy drift。
- MVP: inventory agent identity/owner/credential scope/tool grants/approval policy/last activity，做 periodic drift + retirement evidence；第一版不 custody credentials。
- Pricing: **US$199–499/team/month**。
- Acquisition: SOC2-heavy startups、AI-native IT/security teams、agent platform communities。
- Two-week test: 5 teams、≥20 agents；找到 ≥5 個 stale/orphaned/over-scoped issues，取得 2 個 paid pilots。
- Risks: security liability、IAM integration、Decawork/OneCLI/IdP vendors 原生化。

### 3. Fiduciary AI Verification Gate

- Target customer: boutique legal/tax/compliance AI teams、professional-services consultancies。
- Pain: 正確-looking output 仍可能 citation 不支持 claim、漏 contradiction、違反 instruction contract；model upgrade 可能 silent regress。
- MVP: claim extraction → source-span entailment → entity/date/amount consistency → contradiction search → fixed-case model regression → review packet。
- Pricing: **US$199–999/team/month** 或 **US$500–2,000+** audit。
- Acquisition: legal-tech / tax-tech / compliance communities、boutique consultancies、professional AI integrators。
- Two-week test: 30–50 rights-cleared/synthetic cases、3–5 practitioners；material-defect recall ≥90%、FP <10%，取得 1 個 US$1K audit 或 2 個 US$299/month pilots。
- Risks: privilege/confidentiality、professional liability、source rights、overreliance on automated verification。
