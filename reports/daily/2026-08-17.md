### 最值得執行的藍海方向

#### 1. Harness Switch Regression CI
**Target customer:** AI SaaS / developer-tool teams embedding Codex、Claude Code、Hermes 等 harness。  
**Pain:** protocol 相容，不代表 task-level output / artifact / tool semantics / failure behavior 等價；harness switch 可能 silently regress。  
**MVP:** golden-task replay across 2 harnesses → artifact/tool/file semantic diff → latency/cost/failure comparison → PR-level switch/canary/hold receipt。  
**Pricing:** US$49–199/repo/month；platform/agency US$399+。  
**Acquisition:** HarnessRouter/UHP users、agent SDK vendors、coding-agent product teams。  
**Two-week gate:** 5 teams × 20 tasks；≥3 teams 發現未知 regression，≥2 家接受 US$99/month pilot。  
**Risk:** UHP/conformance suite 原生擴張；moat 必須是 real-world cross-harness fixtures 與 historical compatibility evidence。

#### 2. Agent-Readable Docs Drift Monitor
**Target customer:** API-first SaaS、MCP servers、developer tools。  
**Pain:** code/API 已變，但 Markdown / `llms.txt` / MCP answers 仍舊，agent 直接吸收錯誤 truth。  
**MVP:** Git/OpenAPI diff → semantic impact → affected docs/MCP answers → golden-question replay → PR evidence。  
**Pricing:** US$49–199/repo/month。  
**Acquisition:** Blume/Mintlify/Docusaurus users、MCP maintainers、DevRel teams。  
**Two-week gate:** 5 repos，回放 10–20 次 changes；抓到 ≥3 real drift defects、false-positive <10%、2 個 US$99/month pilots。  
**Risk:** semantic false positives 與 docs platforms 原生化 drift checks。

#### 3. Visual Field-Service Agent QA
**Target customer:** home-service/field-service AI agencies、remote-support software。  
**Pain:** video agents 可看到 camera context，但 wrong-object grounding、unsafe instructions、missed cues 與 escalation failure 會直接造成 operational risk。  
**MVP:** 50 vertical visual fixtures → grounding/safety/escalation assertions → regression report。  
**Pricing:** US$99–399/month 或 US$1K–3K evaluation setup。  
**Acquisition:** Vapi/Retell/Chert ecosystem、field-service agencies。  
**Two-week gate:** 50 fixtures、2 agent stacks、3–5 design partners；≥10 reproducible failures，2 家 US$199/month 或 1 家 US$1K pilot。  
**Risk:** video privacy、Apple/channel dependency、regulated-health liability；先避開 medical/KYC。
