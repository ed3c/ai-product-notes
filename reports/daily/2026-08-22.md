## 最值得執行的三個藍海方向

### 1. Agent Credential Boundary Regression Gate

Target customer：已使用 Claude Code / Codex / Cursor / MCP / autonomous workflows 的 5–100 人 teams。Pain：connector、IdP、repo scope、policy 或 harness 改動後，agent effective permissions 可能 silently widen。MVP：snapshot effective scopes，建立 30–50 個 hidden allow/deny fixtures，每次 policy/connector upgrade replay，輸出 `scope-expanded / approval-bypassed / denial-regressed / safe` receipt。Pricing：US$199–499/team/month。Acquisition：OneCLI / MCP / coding-agent security communities。Two-week gate：5 teams，至少 5 個 material regressions、false-positive <10%，2 個 US$199/month pilots。Risk：security liability、provider-native governance、TLS/credential complexity。

### 2. Agent Runtime Fallback Parity Verifier

Target customer：把 coding/research agents 跑在 managed sandboxes 的 AI SaaS。Pain：provider/sandbox failover 能恢復 execution，不代表 credential scope、filesystem、tools、artifacts 與 retry semantics 等價。MVP：run manifest + dual replay + permission/artifact/tool semantic diff + cutover/hold receipt。Pricing：US$99–299/month 或 US$500–2,000 migration/fallback audit。Acquisition：Epho/E2B/Daytona/agent-runtime users。Two-week gate：5 teams、20 runs/team，至少抓 5 個 fallback-specific mismatches，2 個 paid pilots。Risk：cross-provider nondeterminism、source/secret handling、runtime churn。

### 3. Agent Data Rights & Provenance Receipt

Target customer：B2B enrichment、market intelligence、sales/recruiting agents。Pain：agent 取得 structured web data 後，很難回答每個 field 從哪裡來、何時抓、是否 stale、哪些資料受 source policy / PII constraints 影響。MVP：source/timestamp/extractor/version/transformation chain + sensitive-data flags + policy/schema diff + delete/re-fetch receipt。Pricing：US$99–299/month。Acquisition：Mindcase/Apify/Bright Data/AI enrichment communities。Two-week gate：5 data-heavy teams、1,000 records、10 sources；3 家發現原本無法回答的 provenance/freshness issue，2 個 paid pilots。Risk：不得把 provenance report 宣稱成 legal advice；platform terms 與 data rights 持續改變。
