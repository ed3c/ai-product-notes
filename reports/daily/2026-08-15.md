### 最值得執行的藍海方向

#### 1. Vendor API Blast-Radius CI

- Target customer：API-first SaaS、AI SaaS、支付/通訊/LLM API-heavy engineering teams。
- Pain：vendor changelog 很吵；真正需要的是「哪個 endpoint/field 的變化會打到自己的哪個 call-site」。
- MVP：GitHub App / CI；解析 source calls + vendor OpenAPI specs，建立 call-site map，對 spec/changelog diff 產生 blast-radius report，先不 auto-fix。
- Pricing：US$49–199/repo/month；agency/platform tier US$399+。
- Acquisition：GitHub Marketplace、Stripe/OpenAI/Twilio developer communities、API-first startups。
- 兩週驗證：10 repos × 10 vendors，回放 12 個月 spec changes；至少找到 5 個 relevant breakages、false-positive <10%，並取得 2 個 US$99/month pilots。
- Risk：vendor specs 不完整、dynamic SDKs、責任邊界、oxpecker 本身就是直接競爭。最初應 verticalize，例如 Payments APIs 或 AI Model APIs。

#### 2. Vertical Expert Outcome QA

- Target customer：coaches、consultants、assessment funnels、expert-led B2B services。
- Pain：個人化 AI outcome 可能偏離 expert methodology、產生 unsupported claims、scoring inconsistency，直接傷害品牌與 conversion。
- MVP：expert rubric + 50 synthetic lead profiles + output checker；標記 methodology mismatch、unsupported recommendation、missing next step、score inconsistency。
- Pricing：US$99–299/month，或 US$500–2,000 setup + monitoring。
- Acquisition：Outcome/ScoreApp/Typeform/ClickFunnels ecosystem、creator consultants、niche agencies。
- 兩週驗證：3 experts、50 cases；至少 2 位確認抓到真實品牌/方法論風險，且願付 US$199/month 或 US$500 setup。
- Risk：不同 expert framework 難以標準化；需要 vertical rubric 與 approved-example corpus，而不是 generic LLM judge。

#### 3. Harness Plugin Compatibility Lab

- Target customer：DeepSeek Harness plugin authors、agent-platform teams、MCP/ACP adapter maintainers。
- Pain：developer-preview runtime 高頻 breaking changes，plugin 是否能 boot、register tools/events、replay session、維持 permission contract 都需人工重測。
- MVP：plugin/version → profile boot → 30 golden fixtures → event/tool/policy/session assertions → compatibility report。
- Pricing：US$49–199/plugin/month；private enterprise matrix US$499+。
- Acquisition：DeepSeek Harness plugin topic/Discord/GitHub、agent infrastructure communities。
- 兩週驗證：10 plugins/adapters × 30 fixtures × 2 runtime versions；給 5 maintainers 免費 report；2 個 US$99/month pilot 即通過。
- Risk：upstream 可能推出官方 conformance suite；moat 應是跨版本 fixture corpus、failure taxonomy 與 historical evidence。

Watchlist：Browser Workflow Reliability Pack。BrowserAct 已提供強 managed infrastructure；更適合小團隊的商業層是 vertical workflow replay、schema contracts 與 evidence，而不是 generic browser agent。
