### 最值得執行的三個藍海方向

#### 1. Agent-Readable Docs Drift Monitor
目標：API-first SaaS、developer tools、MCP maintainers。痛點：code/API 改變後 docs、`llms.txt`、`skill.md`、MCP answers 變 stale，造成使用者與 agents 同時讀到錯誤 context。MVP：GitHub diff + OpenAPI diff → impacted docs → citation/retrieval regression → PR/issue review，不自動 publish。收費：US$49–199/repo/month。獲客：GitHub Marketplace、Claude Code/Codex communities、DevRel。兩週實驗：audit 5 個 startup repos；抓到至少一個真實 stale-doc defect 且 2 家願付 US$99/month 才繼續。風險：alert fatigue、private repo security、平台 bundling。

#### 2. Brand Memory & Creative QA Layer
目標：DTC brands、paid-social agencies、small creative teams。痛點：多個 creative agents 產出速度提升後，brand claims、tone、visual rules、offers 與 compliance 更容易漂移。MVP：保存 approved brand memory，對生成 asset 做 claim/policy/visual checklist，輸出 approve/reject reason 與 regression history。收費：US$99–299/month。獲客：Meta agencies、Shopify agencies、creator operators。兩週實驗：對 100 個 historical creatives 回放 QA，替 5 家 agency 免費 audit；2 家付費即通過。風險：creative quality 難 deterministic 評估、平台原生 brand controls。

#### 3. Agent ACL & Audit Gateway
目標：同時使用 Claude Code、Codex、Slack/GitHub agents 的小型 engineering teams。痛點：agent permissions、repo/tool access、agent-to-agent calls 與 destructive actions 缺少統一 policy/audit。MVP：GitHub App + Slack trigger + local daemon；三種 agent identities、repo/tool ACL、human approval 與 action audit。收費：US$199–499/month。獲客：AI-native startups、software agencies。兩週實驗：5 teams shadow-mode，取得 2 個 paid pilot。風險：security liability、upstream open-source bundling、integration support load。
