## Blue-ocean priorities

### 1. AI-Generated Code Release Gate
Target: agent-heavy SaaS teams. Pain: code generation outruns independent release verification. MVP: hidden golden user journeys + browser/API replay + mechanical contracts + ship/hold receipt. Pricing: US$99–299/repo/month. Acquisition: Claude Code/Codex/Cursor communities, GitHub Marketplace, AI-native agencies. Two-week gate: five teams × 20 PRs; find ≥5 release risks missed by existing CI/review, false-positive <10%, close two paid pilots. Risk: QA vendors and GitHub move down-stack; moat is private hidden-oracle corpus and cross-agent regression history.

### 2. Mobile Agent Incident Action Guard
Target: mobile teams using agentic observability. Pain: an agent can propose a plausible production action without enough evidence, correct permissions, or rollback. MVP: incident → hypothesis → evidence links → proposed action → policy/approval → rollback receipt. Pricing: US$199–499/team/month. Acquisition: bitdrift/Sentry/Embrace/OTel mobile teams. Two-week gate: five teams × 20 historical incidents; reduce triage time 30% for three teams and catch ≥5 unsafe/under-evidenced actions; two paid pilots. Risk: production liability and mobile PII.

### 3. Heterogeneous Inference Decision Ledger
Target: AI SaaS spending >US$2K/month on inference. Pain: provider/model/hardware choice is changing faster than procurement evidence. MVP: replay representative traces across configurations and emit quality/latency/cost/TCO Pareto frontier plus decision receipt. Pricing: US$1K–5K benchmark project or US$199–499/month monitoring. Acquisition: inference providers, AI infrastructure communities, FDE/FinOps consultancies. Two-week gate: five teams; three discover >20% material trade-off; one paid benchmark or two recurring pilots. Risk: benchmark staleness and provider-native optimizers.
