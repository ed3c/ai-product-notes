### 最值得執行的藍海方向

#### A. Review Feedback Memory
- Target customer: 已使用 CodeRabbit、Copilot、Claude/Codex review 的 5–100 人 software teams。
- Pain: 多個 AI reviewer 產生大量建議，但 accepted/rejected/discussed feedback 沒有跨 provider 累積成 team memory。
- MVP: 匯入歷史 review outcomes，建立 team-specific preference summary，對新建議提供 prioritization，並每週輸出 recurring rejection patterns 與 accepted-finding rate。
- Pricing: US$49–199/org/month。
- Acquisition: GitHub Marketplace、AI coding communities、software agencies。
- Two-week validation: 5 teams、至少 300 historical comments；通過門檻是 3 家認為能減少重複 review discussion，2 家願意支付 US$99/month pilot。
- Risk: upstream reviewer 原生加入 feedback learning；小團隊歷史資料不足。

#### B. AI App Production Readiness Report
- Target customer: 使用 Lovable、Replit、Bolt、v0 建產品的 solo founders 與 agencies。
- Pain: prototype 很快，但 launch 前的 dependency ownership、operating assumptions、cost visibility 與 handoff quality 不透明。
- MVP: read-only project audit，輸出 dependency map、ownership/export readiness、cost assumptions、launch blockers 與 post-launch checklist。
- Pricing: US$99–499 per audit；agency subscription US$199–999/month。
- Acquisition: vibe-coding communities、founder communities、AI app agencies。
- Two-week validation: audit 10 個真實 AI-built apps；至少 5 份找到原先未注意的 launch concern，取得 2 個 US$199 paid audits 或 1 個 US$499 agency pilot。
- Risk: builders 原生加入 readiness checks；產品退化成客製 consulting。

#### C. Experiment Decision Memory
- Target customer: 使用 GitHub + MLflow/W&B 的小型 ML teams。
- Pain: experiment history、failure explanation 與下一輪 decision 分散，研究者重複理解舊實驗。
- MVP: 匯入歷史 run metadata，整理 experiment timeline、failure clusters 與 decision log，產生 human-reviewed next-step brief。
- Pricing: US$49–299/seat/month；managed workflow US$1K–5K/month。
- Acquisition: ML engineering communities、fine-tuning teams、research startups。
- Two-week validation: 3 teams、各 20+ historical experiments；規劃下一輪時間降低至少 30%，並取得 1 個 US$1K managed pilot 或 2 個 US$199/month subscriptions。
- Risk: workflow 差異大，recommendation value 難量化。

### 今日判斷
